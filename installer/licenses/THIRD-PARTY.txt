DBDesigner Fork - libraries of other projects in the setup program
====================================================================

DBDesigner Fork itself is free software under the GNU General Public
License, version 2 or later (Copying.txt in the program directory).

The setup program installs the following libraries of other projects next
to the program. They are unchanged binaries; the program loads them at run
time when a connection to the database in question is opened.
