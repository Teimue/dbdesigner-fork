General Information

DBDesigner Fork is a free database design system that integrates database design, modelling, creation and maintenance into a single, seamless environment.

It is a community fork of DBDesigner 4, written by fabFORCE.net. The fork was started in 2006; since version 2.0 it is built with Free Pascal and Lazarus instead of Delphi and Kylix.

Platforms and Databases

DBDesigner Fork runs on

  • Windows 10 and Windows 11, 64 bit. The program is DPI aware and scales its dialogs, symbols and the model with the display.
  • Linux with GTK2 (built from the source code).

The following databases can be connected to, for the reverse engineering, the synchronisation, the Query Mode and the plugins:

  • MySQL 8 (client library libmysql.dll / libmysqlclient.so.21)
  • SQLite 3 (client library sqlite3.dll / libsqlite3.so.0)
  • Firebird 3 or newer, as a server or with the embedded engine (client library fbclient.dll)

Oracle, MS SQL Server and ODBC are still listed as drivers in the connection dialogs, but there are no connectors for them yet. The SQL script can be written for more databases than can be connected to (see Export SQL Creates).

Installation

On Windows the setup program from the releases page installs the program, the plugins, this documentation and the client libraries for SQLite, MySQL and Firebird (with the embedded engine); nothing else has to be installed. The example models and the example databases are copied to Documents\DBDesigner. Optionally the setup program installs the MCP server and registers it in Claude Code and Claude Desktop.

The settings, the list of database connections (DBConn.ini) and the list of recent files are stored in %APPDATA%\DBDesigner4\ on Windows and in ~/.DBDesigner4/ on Linux.

The user interface is available in English and German. The language is chosen in [Options]->[DBDesigner Options].

Support

The source code, the releases and the issue tracker are on GitHub: github.com/Teimue/dbdesigner-fork. Select [Help]->[Visit GitHub Project] to open the page from the program.

Bug submission

If you have found a bug or got an idea for new functions and features please open an issue at github.com/Teimue/dbdesigner-fork/issues, or select [Help]->[Submit a bug / feature request].
