MCP Server for AI Assistants

The MCP server DBDesignerMCP lets an AI assistant such as Claude work with DBDesigner Fork models through the Model Context Protocol (MCP). The assistant can read and change models, write the SQL script, reverse engineer a database and compare a model with a database. The server uses the same model classes as DBDesigner Fork, so it reads and writes the model files and the SQL exactly like the program.

The server is a console program without a window. The AI assistant starts it and talks to it on its standard input and output; it is not started by hand.

Installation

The MCP server is an optional part of the Windows setup program (task Install the MCP server, not preselected). It is installed next to the program as DBDesignerMCP.exe. Two more tasks register it in Claude Code (for the current user, all projects) and in Claude Desktop. The uninstaller removes the registrations again.

The registration can also be done later from a command prompt:

DBDesignerMCP --register-claude-code registers the server in Claude Code under the name dbdesigner (the claude command must be installed)
DBDesignerMCP --register-claude-desktop adds the server to claude_desktop_config.json of Claude Desktop
DBDesignerMCP --unregister-claude-code
DBDesignerMCP --unregister-claude-desktop		 remove the registrations
DBDesignerMCP --version shows the version of the server, which is the version of the program

Restart Claude Desktop after the registration. Other MCP clients can start DBDesignerMCP.exe without arguments as a local (stdio) server.

Tools

The assistant first opens a model file (open_model) or starts a new one (new_model). All other tools work on this open model. Changes are kept in memory until save_model writes the model to its file or to another one.

Models open_model, new_model, save_model, get_model_settings, change_model_settings
Tables and columns list_tables, describe_table, add_table, rename_table, change_table, delete_table, add_column, change_column, delete_column, get_standard_inserts, set_standard_inserts
Indices and relations add_index, delete_index, list_relations, add_relation, delete_relation
Diagram move_table, arrange_tables, list_regions, add_region, change_region, delete_region, list_notes, add_note, change_note, delete_note, list_images, add_image, change_image, delete_image, export_model_image (PNG, JPG or BMP)
Datatypes list_datatypes, add_datatype, change_datatype, delete_datatype
SQL export_sql: the SQL create script for a target database, with the options of the Export SQL Creates dialog
Databases list_connections, connect_database, disconnect_database, list_database_tables, reverse_engineer, sync_database

Databases

The database tools work with MySQL, SQLite and Firebird. list_connections shows the database connections stored in DBDesigner Fork; a connection is best used by its name (its stored password is used). Otherwise the driver, the database, the host, the port and the user are given directly; for SQLite and Firebird without host the database is a file. One connection is open at a time. The server reads the settings of the program but never changes them.

sync_database changes the database. Called without its apply parameter it only lists the statements it would execute, so the assistant (and you) can check them first. Tables that exist only in the database are kept.

Message boxes the program would show are not displayed by the server; their text is returned to the assistant as part of the result.
